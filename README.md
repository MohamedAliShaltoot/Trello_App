# Trello Clone (Android)

A simple Trello-inspired task management application built with **Kotlin** and **Jetpack Compose**. The app allows users to manage boards, view cards, and inspect card details through a clean and modern UI.

## Features

* View all boards
* Browse cards within a board
* View detailed card information
* MVVM architecture
* Jetpack Compose UI
* Room Database for local persistence
* Navigation Compose
